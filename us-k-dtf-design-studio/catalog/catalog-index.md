# Catalog index

## Mongolian Trend Words (MTW)

Reserved design IDs: **MTW-001–MTW-020**.

The source conversation references original catalog content, but the actual image files were not available to this project. Each ID is therefore registered without a fabricated title, preview, or artwork.

### Required record for each design

- Design ID
- Exact original filename and extension
- Original checksum
- Source dimensions and resolution
- Color mode and transparency
- Preview generated from the original without editing it
- Production status and approval date
- Print export filename and operator notes

### Status vocabulary

`source_unavailable` → `received` → `verified` → `proof_ready` → `approved` → `archived`
