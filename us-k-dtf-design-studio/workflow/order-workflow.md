# US&K DTF order workflow

1. **Intake** — capture customer, garment, size, quantity, requested design ID, placement, and deadline.
2. **Catalog check** — verify the design ID against the catalog; never substitute an unregistered or invented asset.
3. **Source verification** — confirm the original file, checksum, transparency, dimensions, and license/usage note.
4. **Mockup/proof** — create a labeled proof using a working copy. Keep the original untouched.
5. **Customer approval** — record approved design ID, dimensions, placement, garment color, and quantity.
6. **Preflight** — apply the print-preparation checklist and document any intentional exceptions.
7. **Export** — create a print-ready export in `exports/` with design ID, size, and revision in the filename.
8. **Production QC** — verify transfer dimensions, orientation, color appearance, and order count before pressing.
9. **Archive** — retain the original, approved proof, export, approval record, and QC result together.
